# 真人劇情錄音

目前尚未加入錄音檔；遊戲不會使用合成語音代替。可用手機語音備忘錄，逐段錄製並匯出 M4A、MP3 或 WAV，前後留半秒安靜。錄音將隨公開遊戲讓訪客播放。

| 接點 | 台詞 | 語氣 |
|---|---|---|
| princess | 公主魔法變身！小豬送妳皇冠和寶石！ | 驚喜、溫柔 |
| jewels | 珠寶雨來啦！滿滿的寶石，送給妳！ | 興奮 |
| angry | 哼！你要認真一點啦！看清楚，再試一次！ | 可愛撒嬌，不兇 |
| chase | 哇！母雞追來啦！快跑！ | 俏皮、驚訝 |
| timeout | 砰！時間到！小豬生氣啦！ | 搞笑 |
| finish | 耶！全部到家！謝謝你帶我回家！ | 開心、感激 |

加入音檔後，在根目錄 story-support.js 的 STORY_VOICES 對應 src 填入實際相對路徑，例如 assets/voice/princess.m4a。未提供的 src 保持 null，避免請求不存在的檔案。劇情轉場會等待錄音結束；音檔錯誤、被瀏覽器阻擋或靜音時會安全繼續，不會卡住。每段請控制在 30 秒內。
